# GoldBuilders Client Engagement Showcase Update

This is an additive update based on the latest Conversion Upgrade website package.

## Website changes
- Adds an accessible, touch-friendly client engagement slider to the homepage and Case Studies page.
- Uses the organisation names and engagement areas supplied by the site owner.
- Replaces illustrative case-study blueprints with selected engagement summaries and service-area explanations.
- No invented first-person quotes, testimonials, performance metrics, or fake client logos are shown.
- Slider has manual controls, swipe/scroll snapping, keyboard arrows, pagination dots, responsive card widths, and no auto-rotation.
- Adds contact and WhatsApp calls to action.

## Client names and scope
The summaries are based on information supplied by GoldBuilders. Confirm the right to publicly use each client name and the exact scope before deploying if any engagement is confidential or the client has not authorised public reference. The site does not state that the organisations have approved testimonials.

## Testimonial drafts
`CLIENT-TESTIMONIAL-APPROVAL-DRAFTS.md` is a private approval workflow and is not placed in the public folder. It is not a set of approved quotes. Request or obtain each client's exact approved words before adding first-person testimonials.
