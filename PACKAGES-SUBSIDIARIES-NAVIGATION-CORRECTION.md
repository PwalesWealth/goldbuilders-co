# Packages and Subsidiaries navigation correction

This update restores two separate top-level menus. Packages is an offer menu containing exactly four items. Subsidiaries is its own menu, containing four click-to-expand subsidiary groups and each group's initiatives.

The nested menu controls expose `aria-expanded` and `aria-controls` attributes, support keyboard Escape to close the active top-level menu, close on outside click, and collapse into a single-column accordion on smaller screens. No page content, inquiry form fields, submission handlers, or existing package pricing were removed.
