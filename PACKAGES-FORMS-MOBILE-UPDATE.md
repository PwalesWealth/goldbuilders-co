# Packages, Venture Enquiry Forms & Mobile Fit Update

## Navigation — corrected structure
Packages and Subsidiaries are two separate top-level dropdowns. **Packages** contains exactly four offers: Nexora Business-in-a-box, Strategy and Transformation services, Leadership and Talent Programs, and Executive Strategy Session. **Subsidiaries** is not removed or merged into Packages. It contains four click-to-expand groups: GoldBuilders Co., LuxeStreams, Kohen, and YIELD Global Impact, with each subsidiary's overview and initiatives nested under it. The Explore dropdown remains available.

## Enquiry forms
Dedicated forms were added to the Kohen overview, every Kohen venture page, YIELD Global Impact and each named initiative page, plus BeMore, LuxeStreams, each GoldBuilders programme detail page, and the corporate/government institutional pages. Each form has a fixed destination/service, page-specific enquiry choices and tailored prompts. The common contact endpoint stores the page-specific choice with the submitted message; no schema change is required. LuxeStreams Concierge Club retains its separate guided signup.

## Mobile fit
Responsive CSS addresses overflowing text, balanced headings, adaptive grids, readable form fields, wrapped CTA buttons, and mobile accordion menus. Packages becomes a compact list; Subsidiaries becomes a four-family accordion. The existing dark-and-gold visual theme and page content are retained.

## Validation and deployment
Navigation was updated across 57 pages. The exact four package labels and four subsidiary accordion controls were validated, and all local primary-navigation links resolve. JavaScript syntax and ZIP integrity checks passed. The site has not been deployed to production; visual testing on a physical mobile device remains a deployment-stage check.
