# GoldBuilders subsidiary menu integration kit

The shared Subsidiaries dropdown is separate from Packages. It contains four click-to-expand groups: GoldBuilders Co., LuxeStreams, Kohen, and YIELD Global Impact. Each group contains links to its initiatives.

For an independently hosted ecosystem site, include `subsidiaries-menu.css` and `subsidiaries-menu.js`, then add `<div data-gb-subsidiaries data-base="https://YOUR-GOLDBUILDERS-ROOT/"></div>` where the Subsidiaries menu should appear. Set `data-base` to the actual GoldBuilders root URL.

The embedded GoldBuilders website navigation is already wired to the same information architecture. The Packages menu contains only Nexora Business-in-a-box, Strategy and Transformation services, Leadership and Talent Programs, and Executive Strategy Session.
